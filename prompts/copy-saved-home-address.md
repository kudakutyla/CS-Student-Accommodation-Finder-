# Add copy-address action to saved homes

On the student Saved Homes page, make the displayed address interactive. When
the student activates it, reveal a nearby “Copy address” button; do not copy
automatically on address press. Clicking the button copies that listing's full
address to the clipboard and provides clear success or failure feedback, with
accessible labels and keyboard operation. Keep the existing blue address styling,
layout, and listing navigation intact, and avoid turning the containing listing
row into a navigation target. Verify lint and TypeScript checks.
