# Add icons to student dashboard actions

In `frontend/app/student/dashboard/page.tsx`, add the existing Lucide `Search` icon to the
“Search homes” link and `Bookmark` icon to the “Saved homes” link. Keep the links'
destinations, labels, sizes, spacing, and responsive layout. Icons are decorative and should
be hidden from assistive technology so the link accessible names remain unchanged.

Run frontend TypeScript and targeted ESLint checks and verify both icons and labels render
at mobile width.
